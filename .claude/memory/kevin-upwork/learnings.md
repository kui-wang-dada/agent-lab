## 2026-06-02 — 海外现有客户 grant-funded 追加需求（GBP 计价）
**情境**：Venus 之外某海外客户（"Kui, I hope you're well"语气=老关系）申请到 1k GBP grant，想用这笔钱雇 Kevin 做 ticketing + 安全加固，让 webapp 更专业。Kevin 问"1k GBP 折人民币多少 / 该如何报价"。
**经验**：grant 是固定盘子（1k GBP ≈ ¥9k 量级，汇率随行就市需当场查），不是开放预算——此时"报预算 80%"的固定价规则要让位给"在 grant 上限内框出能交付的最小可信范围"，超出部分明确单列为后续阶段。
**下次怎么做**：遇到"我申请到 X 金额的 grant 来雇你"——先确认 grant 是否含平台手续费/税，再按 grant 净额报"这笔钱能买到的明确 scope"，把 security 这种无底洞需求显式封边界。
**适用场景**：海外老客户 / 非美元小额预算（GBP/EUR）/ grant 或固定补助资助的活。
**结果（2026-06-08 Kevin 确认）**：最终**未接**，仅停留在询价 / 汇率换算咨询阶段，没有正式报价或签约。上面的报价口径教训（grant 是固定盘子、security 需显式封边界）仍保留备用，适用于下次同类 grant-funded 询价。
