## 2026-06-05 — 微信小程序死线项目，备案审批是头号风险，不是技术选型
**情境**：正大集训小程序，客户死线 7-20，仅 33 工作日。Kevin 倾向复用 dongjiaoshan 的 RuoYi 小程序+admin。
**经验**：微信小程序上线要过三道**串行**审批——ICP 域名备案(7-20工作日)→小程序备案(7-14)→代码审核(1-7)，最快15最慢41天，可能直接超死线。且**集训期改代码要重新提审 1-7 天**，对"活动当周热修"是致命的。RuoYi 复用的"开发提速"真实存在，但救不了"备案串行等待"和"集训期热修要重审"这两刀——加钱加人都买不回审批端的时间。H5 方案省掉小程序备案+代码审核(8-21天)且能秒级热修，正好填死线缺口。
**下次怎么做**：①遇微信小程序+紧死线，第一句话先问客户"有无 ICP 备案域名 + 认证企业小程序主体"——这一条决定整条路线，不是技术偏好决定。②大企业（正大这种）大概率已有备案资产，若有则小程序复用 RuoYi 成立、风险骤降；若无则强制 H5 保命。③小程序路线下要活，必须"代码冻结+数据热配"（打卡点/题目/规则/文案全做成后台可配数据，改数据不改代码不提审）。
**适用场景**：任何微信小程序 + 紧死线 / 活动支撑类项目。

## 2026-06-05 — 死线项目报价要拆"赶工溢价+值守费+冻结条款"，不能按常规项目翻版
**情境**：正大集训小程序报价。dongjiaoshan 是"做完即可"无物理死线，正大死线钉死在活动档期不可滑动。
**经验**：①死线项目报价多三个加价因子：赶工溢价(+15~20%)、集训期值守费(按天单结，不含在开发费里)、并发/不丢数据保障工程。②报价口径仍沿用 dongjiaoshan 的"按人写报价 + AI 接管是利润"套利逻辑（人天 ¥1300~1800 对甲方报，有效时薪 ¥600-1000/h）。③付款节点把"上线前"放 45%（高于验收），避免完工后甲方以"活动还没开始/还想改"拖款；预付提到 35%（死线项目前期重投入）。④**需求冻结条款是死线项目的命门**：设冻结时点(签约后几天内)+冻结后变更单独报价且不保证按期+甲方供料 deadline+顺延条款。⑤"500并发不断连"绝不签无限责任 SLA，软化为"系统侧不成瓶颈+关键数据不丢+断网补传"，运营商/现场WiFi 因素免责。
**下次怎么做**：死线活动类项目，报价永远给"砍范围保上线的 MVP 档" + "完整功能不绑死线的 V2 档"两档，并站在甲方利益讲"集训期间用不上的功能(日志/互评/报表/导出)放 V2 还省赶工溢价"——这是真实建议不是挤功能。
**适用场景**：任何有不可滑动物理死线的国内项目（活动/赛事/发布会支撑系统）。
